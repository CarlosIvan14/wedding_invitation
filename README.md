# Invitación de boda y bautizo

Sitio React/Vite para la boda de Candy y Agustín y el bautizo de Gael Imanol.

## Ejecutar

```powershell
npm install
npm run dev
```

Abre la dirección que muestre Vite, normalmente `http://localhost:5173`.

## Producción

```powershell
npm run build
```

La versión lista para publicar se generará en `dist/`.

## Confirmaciones

La pantalla incluye validación y confirmación visual. Para enviar los RSVP a WhatsApp o a una base de datos hace falta el enlace del grupo de WhatsApp, un número de destino o el servicio donde se guardarán las respuestas.
